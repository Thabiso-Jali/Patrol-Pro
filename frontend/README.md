# Patrol Pro Frontend

Patrol Pro is an MVP intended for controlled demonstration and pilot evaluation. It is not currently approved as the sole system for live security operations.

This is a simple React frontend for the Patrol Pro backend.

## Setup

```bash
cd frontend
npm install
npm start
```

For local development, the app can use `http://127.0.0.1:8000`. Production
builds require an explicit deployed API origin.
