# Patrol-Pro

Patrol Pro is an MVP intended for controlled demonstration and pilot evaluation. It is not currently approved as the sole system for live security operations.

The current FastAPI and React implementation provides organisation-scoped
authentication, permissions, staffing, patrol, incident, checkpoint and
dashboard foundations while the controlled-pilot readiness programme is
completed.

For a safe Render test/demo rollout, follow the
[demo deployment guide](docs/DEPLOYMENT_DEMO.md).
